# BlueNxt - World's First HR ConsulTech Website

A production-ready, responsive multi-page marketing website for **BlueNxt** (bluenxt.ai), the "World's First HR ConsulTech", built with React, Vite, TypeScript, Tailwind CSS, and React Router.

## Design System

- **Background:** `#0B111E` (Deep navy)
- **Cards:** `rgba(17,25,44,0.65)` with 1px border `rgba(255,255,255,0.08)`, backdrop blur, rounded-2xl
- **Text:** Primary `#F8FAFC`, Secondary `#94A3B8`
- **Primary Blue:** `#3C83F6`
- **Cyan Accent:** `#21D5ED`
- **Amber Highlight:** `#FBBD23`
- **Alert Red:** `#EF4343` at 80%
- **Signature Gradient:** `linear-gradient(135deg, #3C83F6, #21D5ED)`

## Design System (v2)

- **Fonts (self-hosted via npm, no Google dependency):** Bricolage Grotesque for headings, Instrument Sans for body, Geist Mono for small data. Fluid sizes: `text-display`, `text-h2`, `text-lead`.
- **Colours:** midnight `#070F1E`, surface `#0E1830`, Bluenxt blue `#2F6BFF`, cyan `#22D3EE`, amber `#F5B544` (human accent), light paper sections `#F3F6FB`.
- **Header:** real logo, transparent over heroes then glass on scroll, hover mega-menus (Consulting, AI Platforms), full-screen mobile drawer with accordions. Platform links deep-link with `/platform#<id>`.

## Deploy to GitHub Pages

Everything is set up: `.github/workflows/deploy-pages.yml` builds and publishes on every push to `main`, and `npm run build:pages` prepares the files Pages needs (a page file per route, `404.html`, clean `/manish` and `/sneha`).

1. Run `npm install` and `npm run fetch-brand-assets` locally, so `package-lock.json` and `public/brand/` images exist, and commit them.
2. Push the project to a GitHub repository (public on free plans).
3. Repository **Settings → Pages → Source: GitHub Actions**.
4. **Settings → Pages → Custom domain**: `bluenxt.ai` (or a test subdomain first, e.g. `new.bluenxt.ai`), then **Enforce HTTPS**.
5. DNS at your domain registrar:
   - `bluenxt.ai` → A records `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `www` (or a test subdomain) → CNAME `<your-github-username>.github.io`

Use a custom domain: the site expects to be at the root of a domain, so the default `username.github.io/repo-name/` address won't display correctly.

## Before launch: save Bluenxt's own images

The home hero (hand visual) and the Knowledge Hub photos are Bluenxt's own images from the current bluenxt.ai site. Run this once so the new site hosts them itself (needs internet):

```bash
npm run fetch-brand-assets
```

They are saved into `public/brand/`. Until then they load from the live bluenxt.ai address, which will stop working once this site replaces the old one.

## Digital business cards

`public/manish/` and `public/sneha/` are the founders' contact pages, published at `bluenxt.ai/manish/` and `bluenxt.ai/sneha/` (the QR codes on the printed cards). The corporate brochure is `public/bluenxt-corporate-brochure.pdf`, shared by both cards and the About page. Hosting rules for `.vcf` files and the no-slash addresses are included for Apache (`.htaccess`), Netlify (`_redirects`, `_headers`) and Vercel (`vercel.json`).

## Photos & Videos

All media is set in **`src/config/media.ts`**, and every video is hosted on the site itself in `public/media/`.
- Home hero: the Bluenxt brand film (`bn-ecosystem-future-of-hr.mp4`, compressed to 3.3 MB, audio removed).
- Inner pages: each has its own 10-second cinematic loop in the brand film's style (3D, HUD, teal and amber glow), generated by `tools/render_videos.py`. Replace any of them with your own footage by dropping an MP4 into `public/media/` and updating `media.ts`.
- Partner logos: put official logo files in `public/logos/` (see the README there). Until a file exists, the partner's name shows as text.
- Photos are Bluenxt's own brochure photography in `public/photos/` (no external image services).

## Sample content

Case-study pages (`/resources/...`), legal pages and Careers contain placeholder text, marked with a small amber notice. Replace the content, then set `SHOW_DRAFT_NOTICES = false` in `src/config/site.ts` to hide the notices.

## Motion

Video/photo backdrops with overlay, grid, neural canvas and scanline; home hero load sequence; scroll progress bar; sections and cards rise in on scroll; cursor spotlight on cards; count-up stats. All motion stops for visitors with "reduce motion" switched on.

## Functional Features

- **Global Contact & Demo Modal:** All primary CTAs (`Book a Discovery Call`, `Schedule a Demo`, `Schedule a Call`, `Get Started`, `Book a Platform Demo`) launch a shared lead capture modal with domain pre-selection and form validation.
- **Client-Side Forms:** Newsletter subscription and Digital Agents early access forms include instant client-side validation and confirmation feedback.
- **SEO & Social Sharing:** Custom page titles per route, Open Graph metadata, `sitemap.xml`, and `robots.txt`.
